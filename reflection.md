# Reflection after completing sds project

## What advice would you give to yourself if you were to start a project like thsi again?
- I would frontload my work instead of backloading it, so I could actually finish the project instead of having to leave it as a half-finished prototype. Also, I should not have underestimated the trouble I would face in building a smooth pathfinding algorithm that can be applied to hundreds of units at once.

## What was the hardest part of the project?
- It was definitely making the pathfinding algorithm + fixing the bugs. That alone, from starting to learn it to finally comepleting it, took 4-5 weeks.
